# 📱 Aplicación Android – Marketplace

Aplicación Android tipo marketplace desarrollada en **Kotlin**, con consumo de **API REST**
y autenticación segura mediante **JWT**.

---

## 🧩 Tecnologías utilizadas
- Kotlin
- Android Studio
- Arquitectura **MVVM**
- Retrofit
- Spring Boot (Backend)
- JWT
